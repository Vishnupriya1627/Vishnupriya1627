### 🚀 Featured Projects

#### 🛒 [StockFlow — Flash-Sale Inventory Platform](https://stock-flow-nu-nine.vercel.app/)
`React.js` `Node.js` `Express` `MongoDB` `Redis` `Socket.IO` `k6`

Built a high-concurrency flash-sale system that solves real distributed-systems problems:
- ⚡ Eliminated overselling with a **Redis Lua script** for atomic inventory decrements
- ⏱️ Auto-releasing reservation system using key expiry + sorted-set expiry index
- 🚦 Real-time waiting-room queue with atomic buyer promotion under capacity
- 🧪 Load-tested with **k6** simulating 300 virtual users / 800 concurrent requests — zero overselling, zero data corruption

**[🔗 Live Demo](https://stock-flow-nu-nine.vercel.app/)** · **[💻 GitHub](https://github.com/Vishnupriya1627/stockflow)**

#### 🤖 [ContextKeeper — AI GitHub Context Assistant](https://context-keeper-ten.vercel.app/)
`React.js` `Node.js` `Socket.IO` `MongoDB` `Tailwind CSS` `Docker`

A Dockerized full-stack app that auto-generates versioned developer context from repo history:
- 🔍 Analyzes GitHub repos & commits using Hugging Face transformer models
- 🔐 GitHub OAuth 2.0 integration with secure token exchange
- 📝 Document version control system with diff comparison & rollback
- 🐳 Multi-stage Docker builds deployed behind Nginx

**[🔗 Live Demo](https://context-keeper-ten.vercel.app/)** · **[💻 GitHub](https://github.com/Vishnupriya1627/Context-keeper)**
